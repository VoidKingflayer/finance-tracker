# ФинТрекер (Finance Tracker) — Мультивалютный учет доходов и расходов

Современное веб-приложение для ведения личных финансов в трех валютах: **GEL (Лари, ₾)**, **USD (Доллар, $)** и **RUB (Рубль, ₽)**.

---

## 🌟 Основные возможности

1. **Мультивалютность (3 валюты)**:
   - **GEL (Лари)** 🇬🇪
   - **USD (Доллар)** 🇺🇸
   - **RUB (Рубль)** 🇷🇺
   - Для каждой валюты ведется отдельный автоматический расчет: **Доходы**, **Расходы** и **Чистый остаток (Баланс)**.
   - **Общий капитал**: карточка суммарного баланса с конвертацией в любую выбранную базовую валюту по настраиваемым курсам.

2. **Запись операций (Автоматическое суммирование и вычитание)**:
   - Переключатель **Расход (-)** / **Доход (+)**.
   - Быстрый выбор валюты (GEL, USD, RUB).
   - Ввод суммы, даты и комментария.
   - Баланс пересчитывается мгновенно в реальном времени.

3. **Гибкое управление темами и категориями**:
   - Предустановленные темы (Еда 🍔, Коммуналка 🏠, Транспорт 🚗, Кафе ☕, Здоровье 💊, Зарплата 💰, Фриланс 💻 и др.).
   - Возможность создавать **собственные темы/категории** с выбором иконки (эмодзи), цвета и типа операции (расход, доход или оба).
   - Удаление и редактирование пользовательских тем.

4. **Интерактивная аналитика и круговая диаграмма (Donut Chart)**:
   - Наглядная диаграмма распределения расходов по темам.
   - Фильтрация аналитики: по всем валютам сразу или по конкретной валюте.
   - Список категорий с процентными долями и суммами.

5. **История операций и фильтры**:
   - Живой поиск по заметкам и названиям.
   - Фильтрация по типу (Все / Расходы / Доходы).
   - Фильтрация по валюте и темам.
   - Возможность удаления любой записи.

6. **Сохранение и экспорт**:
   - Все данные автоматически сохраняются в браузере (`LocalStorage`).
   - Кнопка **«Загрузить примеры записей»** для быстрого ознакомления.
   - **Экспорт/импорт в JSON** (создание резервной копии).
   - **Экспорт в CSV (Excel)** с поддержкой кодировки UTF-8 для просмотра в таблицах.

7. **Дизайн и эргономика**:
   - Премиальный современный интерфейс (Glassmorphism, плавная анимация).
   - Поддержка **Темной** и **Светлой** темы (переключение по кнопке с солнцем/луной).
   - Полная адаптивность под компьютеры, планшеты и мобильные устройства.

---

## 🚀 Как запустить

### Вариант 1 (Быстрый запуск через браузер):
Просто откройте файл `index.html` двойным кликом в любом браузере (Chrome, Edge, Firefox, Safari).

### Вариант 2 (Через локальный сервер):
1. Откройте терминал в папке проекта:
   ```bash
   python -m http.server 8080
   ```
2. Откройте в браузере: `http://localhost:8080` (или дважды нажмите на `start.bat`).
